# OpenAvi コントリビューションガイド

OpenAvi プロジェクトにご関心をお寄せいただきありがとうございます！
本プロジェクトは、AviUtl および拡張編集プラグインの操作感・資産互換性を引き継ぎながら、現代の 64bit マルチコア CPU と GPU (Vulkan / DirectX 12 / Metal) で高速動作するオープンソース動画編集ソフトウェアを構築することを目的としています。

## 開発環境のセットアップ

- **Rust**: `1.80` 以降（`rustup` 推奨）
- **OS**: Windows 10/11 (最優先), Linux, macOS

```bash
# 全クレートの単体・結合テスト実行
cargo test --workspace

# デスクトップアプリの起動
cargo run -p au2-app
```

## クレート構成の原則

- **`au2-core`**: UI や特定のファイル形式に依存しない純粋なデータモデルを保ちます。
- **`au2-exo`**: `.exo` の読み書きとラウンドトリップ性を保証します。未知のキーや将来の拡張パラメータを欠落させない設計を維持してください。
- **`au2-plugin`**: `.anm` / `.obj` / `.cam` / `.scn` / `.tra` スクリプトおよび `.auf` / `.aui` / `.auo` / `.auc` ネイティブプラグインのメタデータ解析とブリッジ機構を担当します。
- **`au2-app`**: `eframe` (`egui` + `egui_dock` + `wgpu`) を用いたフロントエンド UI です。1フレーム単位のレスポンスを損なわないよう、重い処理は UI スレッドをブロックしない設計としてください。

## Pull Request の送り方

1. リポジトリを Fork し、機能単位のブランチを作成します。
2. 変更に対するテスト（特に `au2-core`, `au2-exo`, `au2-plugin`）を追加し、`cargo test --workspace` がすべて通ることを確認します。
3. 変更内容と背景を記載して Pull Request を作成してください。
